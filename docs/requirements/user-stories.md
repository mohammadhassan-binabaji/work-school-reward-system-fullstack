# User Stories

## Administrator

- As the initial system owner, I want the first administrator account added manually so that the school can begin using the system.
- As a school administrator, I want to create administrator, teacher, and student accounts with names, usernames, passwords, and optional profile images so that users can access the system with visual identification.
- As a school administrator, I want to bulk import students via Excel with an optional ZIP archive of photos so that multiple accounts and their avatars can be created at once.
- As a school administrator, I want to see user avatars in the users table so that I can easily recognize users visually.
- As a teacher, I want to see student avatars in my class rosters on the classes page so that I can visually identify students when reviewing progress or awarding points.
- As a student, I want to see the profile images of the top 3 students on the leaderboard podium so that top achievers are prominently recognized.
- As a school administrator, I want to sign in with my national ID and password so that I can access administrative functions.
- As a school administrator, I want to create classes so that the school structure is represented in the system.
- As a school administrator, I want to edit classes and subjects so that curricular structures stay up-to-date.
- As a school administrator, I want to delete obsolete classes and subjects so that inactive or mistakenly created records are removed.
- As a school administrator, I want to assign each student to a class so that membership is managed centrally.
- As a school administrator, I want to assign teachers to classes by subject so that teaching relationships are explicit.
- As a school administrator, I want to manage rewards with prices, inventory, and an optional approval requirement so that students can redeem available rewards.
- As a school administrator, I want to review and approve or decline reward requests that require approval so that only valid requests are fulfilled.
- As a school administrator, I want to mark reward requests as received after handing the reward to the student so that delivery is tracked.
- As a school administrator, I want to fund teacher point balances from the system point pool so that teachers have award budgets.
- As a school administrator, I want to define tasks for point transfers and configure point-amount options for each task so that teacher awards follow controlled rules.
- As a school administrator, I want to adjust student point balances so that corrections and administrative awards are possible.
- As a school administrator, I want to deactivate teachers without losing their balances or relationships, while preventing their actions.
- As a school administrator, I want to remove teachers from individual class assignments without changing their balances so that I can manage balances separately.
- As a school administrator, I want complete point-flow audit history and filtered reports so that I can review and manage the school's point economy.
- As a school administrator, I want to filter reports by date range, student, teacher, class, subject, action type, and reward and export them as CSV, Excel, or PDF so that I can analyze and share point activity.
- As a school administrator, I want to view current student points in tables and diagrams so that I can understand point distribution.
- As a school administrator, I want to define and change five student tiers, their minimum point thresholds, pre-defined color themes, and custom motivational messages so that student standing and gamification can be configured.
- As a school administrator, I want to filter reports by student tier so that I can analyze point activity by tier.
- As a school administrator, I want to see school-wide and class top-student boards so that I can identify students with the highest current points.
- As a school administrator, I want inactive, deactivated, and departed students excluded from rankings so that rankings represent active students.
- As a school administrator, I want to create and manage challenges and missions with fixed point values so that students can earn points through defined activities.
- As a school administrator, I want to configure how many times each student may complete a challenge or mission so that activity repetition is controlled.
- As a school administrator, I want to manually review student challenge and mission verification requests so that I award points only for valid completions.
- As a school administrator, I want to replace a challenge or mission when its point value must change so that completed activities retain their original value.
- As a school administrator, I want rejected verification attempts retained and counted so that repeated invalid submissions can trigger the defined activity ban.
- As a school administrator, I want to unban or unblock a student from the student's profile or details page so that I can override an activity submission ban.
- As a school administrator, I want to review, approve, or decline student task proposals so that voluntary student initiatives can be recognized.
- As a school administrator, I want to set and adjust the point value for approved student task proposals so that appropriate point rewards are assigned.
- As a school administrator, I want to mark student task proposals completed so that points are transferred upon successful task execution.
- As a school administrator, I want to filter task proposals by status so that I can manage open and historical proposals efficiently.
- As a school administrator, I want to create, edit, and delete point earning guidance cards so that students can see how to earn points.
- As a school administrator, I want to receive in-app notifications when students submit reward requests requiring approval, task proposals, proposal messages, or activity verification requests so that I can promptly review them.
- As a school administrator, I want to view my notifications, filter them by read status, and see an unread badge counter so that I can track pending alerts.
- As a school administrator, I want unread notifications to be marked as read after I view them and to mark all unread notifications as read with one action so that my inbox remains manageable.

## Teacher

- As a teacher, I want to sign in with my national ID and password so that I can access my account.
- As a teacher, I want to award positive points to students in my assigned classes so that I can recognize student actions.
- As a teacher, I want to select a predefined task and one of its point-amount options when awarding points so that awards follow administrator-defined rules.
- As a teacher, I want my award budget to be enforced so that I cannot spend more than my available balance.
- As a teacher, I want useful reports about my point transfers and student awards so that I can review my point activity.
- As a teacher, I want to filter and export reports as CSV, Excel, or PDF so that I can review relevant point activity.
- As a teacher, I want to view current points for students in my assigned classes in tables and diagrams so that I can monitor their progress.
- As a teacher, I want to filter student point reports by tier so that I can analyze students by current-point category.
- As a teacher, I want to receive an in-app notification when an administrator transfers points to my balance so that I know my award budget has been updated.
- As a teacher, I want to view my notifications, filter them by read status, and see an unread badge counter so that I stay informed of balance changes.
- As a teacher, I want unread notifications to be marked as read after I view them and to mark all unread notifications as read with one action so that my notification list stays up to date.

## Student

- As a student, I want to sign in with my national ID and password so that I can access my account.
- As a student, I want to view my points so that I know what I can redeem.
- As a student, I want to request rewards using my points so that I can receive benefits for my achievements.
- As a student, I want to see the state of my reward request so that I know whether it is pending to approve, pending to receive, completed, or declined.
- As a student, I want a report of my point activity so that I can understand points received, reserved, returned, and spent.
- As a student, I want to see my current rank in my class and across the school so that I can understand my standing.
- As a student, I want to see my current tier based on my points so that I can understand my current-point category.
- As a student, I want my points card on the dashboard to reflect my current tier and next tier colors and show inspiring motivational messages and countdowns so that I am motivated to reach higher tiers.
- As a student, I want students tied on current points to share a rank so that rankings reflect equal standings.
- As a student, I want to view school-wide and class top-student boards so that I can compare current-point standings.
- As a student, I want to see my own rank and points and the names, ranks, and points of top students so that I can understand the leading standings without viewing every student's data.
- As a student, I want to view my weekly end-of-day current-balance history in diagrams so that I can understand my recent progress.
- As a student, I want the system to retain my highest current-point balance so that my highest point level is recorded.
- As a student, I want to complete challenges and missions to earn points.
- As a student, I want to submit a verification request for a challenge or mission so that an administrator can validate my completion and award the points.
- As a student, I want an activity to become done for me after reaching its configured completion limit so that I know I cannot submit more verification requests.
- As a student, I want to know when I am temporarily blocked from submitting a verification request for an activity after three rejections.
- As a student, I want to propose voluntary tasks to earn points so that I can demonstrate initiative.
- As a student, I want to see the status and assigned point value of my task proposal so that I know what is required.
- As a student, I want to cancel my task proposal while it is in ready to do state if I am unable to perform it.
- As a student, I want to exchange messages with the administrator regarding my task proposal so that we can communicate about the task.
- As a student, I want to view point earning guidance cards so that I can understand the ways I can earn points.
- As a student, I want to receive in-app notifications when my reward request status changes, an administrator reviews or replies to my task proposal, points are awarded or adjusted, or my activity verification is reviewed so that I stay informed of my activities.
- As a student, I want to view all my notifications and filter them by unread or read status so that I can easily find relevant updates.
- As a student, I want to see an unread notification count indicator so that I immediately know how many unread updates I have.
- As a student, I want an unread notification to be marked as read after I view it in my inbox so that my unread count updates automatically.
- As a student, I want to mark all my unread notifications as read with a single button so that I can quickly clear pending alerts.
- As a student, I want each notification to include a reference to the related item so that I can navigate directly to the relevant request or proposal page.
