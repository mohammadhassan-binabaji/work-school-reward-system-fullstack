# Changelog

## 4.0.0 - 2026-11-20

### Added

- Added versioned Android update metadata with per-distribution availability and release notes.
- Added collapsed user-facing release notes and channel selection to the Android update flow.

### Changed

- New Android builds compare numeric `versionCode` values and read `app-version-v2.json`.
- Preserved the legacy `app-version.json` format for previously installed app versions.

## 3.2.6 - 2026-11-20

### Changed

- Disabled activity submissions while a verification request is pending.

## 3.2.5 - 2026-11-19

### Added

- Added a show/hide password control to the Student login form.

## 3.2.4 - Initial implementation

- Initial implementation of the Student frontend.
- No Student frontend changes were included in the Admin grade-filter update.
