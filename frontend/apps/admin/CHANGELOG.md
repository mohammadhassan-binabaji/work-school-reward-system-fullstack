# Changelog

## 2.4.5 - 2026-11-20

### Added

- Added explicit fund/return controls for teacher and vice-principal budgets in pool management.

## 2.4.4 - 2026-11-19

### Added

- Added a show/hide password control to the Admin login form.

## 2.4.3 - 2026-11-19

### Added

- Added a Persian RTL page for composing and sending custom notifications to selected students and teachers.
- Added role-aware recipient selection, student class and grade filters, name and national-ID search, mixed admin sends, and recipient-count confirmation.
- Added class, grade, and student search filters to reward requests, verification submissions, and activity proposals.
- Added reward-title filtering to reward requests and activity-title filtering to verification submissions.
- Added Persian and Arabic-Indic digit normalization for national-ID searches across the new review filters.

## 2.4.2 - 2026-11-19

### Added

- Added class-name filters to the Users and direct-adjustment views, alongside grade-level filters.
- Added an “All classes” option and a “No class” option for students without an assigned or named class.
- Kept the existing role and status filter group anchored when the student-specific filters appear.

### Changed

- Made class options depend on the selected grade and reset an incompatible class selection when the grade changes.
- Aligned direct-adjustment search and filter controls with the Users view layout.

### Fixed

- Improved the Vice Principal balance card background so its content is clearly visible.

## 2.4.1 - 2026-11-19

### Added

- Added grade-level filtering to the Users view for student listings; it appears for Admins when Student is selected and always for Vice Principals.
- Added grade-level filtering alongside search on direct-adjustment pages. The no-grade option includes students without a class and students in classes without a grade level.

### Changed

- Widened the direct-adjustment layouts and made the search/filter controls responsive.

## 2.4.0 - Initial implementation

- Initial implementation of the Admin frontend.
